Система управления мероприятиями образовательной организации



Учебный проект по теме №18.



&#x09;Назначение проекта



Система предназначена для автоматизации управления мероприятиями образовательной организации. Она позволяет создавать и публиковать мероприятия, регистрировать участников, назначать помещения, составлять программы и оформлять результаты.



&#x09;Архитектура



Документация по архитектуре находится в каталоге docs/architecture/.



В каталоге представлены следующие материалы:



architecture.md — описание архитектурного решения.

ADR-001.md — обоснование выбора архитектурного стиля.

diagrams.drawio — диаграммы проекта.



&#x09;Ограничения проекта



\* Размер команды: 3 человека.

\* Срок разработки: 4 месяца.

\* Общая трудоёмкость: 12 человеко-месяцев.
