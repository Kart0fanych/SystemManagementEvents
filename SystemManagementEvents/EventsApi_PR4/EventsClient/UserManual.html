Руководство пользователя

Система управления мероприятиями образовательной организации

1. Назначение программы

Приложение предназначено для просмотра, создания и поиска мероприятий образовательной организации. Работа с данными осуществляется посредством взаимодействия с серверным Web API.

Для полноценной работы приложения необходимо предварительно запустить сервер EventsApi.

2. Загрузка мероприятий

  1. Запустите приложение.
  2. Нажмите кнопку «Загрузить мероприятия».
  3. Дождитесь завершения загрузки.
  4. Полученные записи появятся в таблице.

Во время загрузки отображается индикатор выполнения. При необходимости операцию можно отменить кнопкой «Отмена».

3. Создание мероприятия

Для добавления новой записи заполните следующие поля:

  • Название мероприятия — от 5 до 150 символов.
  • Дата мероприятия — дата проведения.
  • Место проведения — название аудитории.
  • Количество участников — от 1 до 500.

После заполнения полей нажмите кнопку «Добавить мероприятие». При успешном создании запись будет добавлена на сервер, а таблица обновится.

4. Поиск мероприятий

Для поиска введите название мероприятия или аудиторию в поле поиска и нажмите кнопку «Найти».

Для отображения полного списка нажмите кнопку «Сбросить». Поиск выполняется по уже загруженным данным.

5. Отмена загрузки

Если загрузка выполняется слишком долго, нажмите кнопку «Отмена». Приложение прекратит выполнение текущего запроса и восстановит доступность элементов управления.

6. Обработка ошибок

  • Ошибка заполнения: проверьте правильность введённых данных и исправьте поля, отмеченные значками ошибок.
  • Аудитория занята: выберите другую аудиторию или дату проведения.
  • Ошибка подключения: убедитесь, что сервер EventsApi запущен и доступен.
  • Тайм-аут: повторите операцию позднее.

7. Дополнительная информация

Для получения информации о версии приложения откройте меню «Справка» и выберите пункт «О программе».
