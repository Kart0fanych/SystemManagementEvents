Руководство пользователя

Система управления мероприятиями образовательной организации

1. Назначение программы

Приложение предназначено для просмотра, создания и поиска мероприятий образовательной организации. Работа с данными осуществляется посредством взаимодействия с серверным Web API.

Для полноценной работы приложения необходимо предварительно запустить сервер EventsApi.

2. Подготовка к работе

Перед началом работы необходимо выполнить следующие действия:

  1. Убедиться, что на компьютере установлена необходимая среда выполнения .NET.
  2. Запустить серверное приложение EventsApi.
  3. Убедиться, что сервер доступен по адресу http://localhost:5289.
  4. При необходимости проверить доступность API через Swagger: http://localhost:5289/swagger.
  5. Запустить клиентское приложение EventsClient.

После выполнения этих действий приложение готово к работе.

3. Загрузка мероприятий

  1. Запустите приложение.
  2. Нажмите кнопку «Загрузить».
  3. Дождитесь завершения загрузки данных с сервера.
  4. Полученные записи появятся в таблице.

Во время загрузки отображается индикатор выполнения. После получения данных приложение показывает количество загруженных записей.

При необходимости операцию можно отменить кнопкой «Отмена».

4. Создание мероприятия

Для добавления новой записи заполните следующие поля:

  • Название мероприятия — от 5 до 150 символов.
  • Дата мероприятия — дата проведения.
  • Место проведения — название аудитории.
  • Количество участников — от 1 до 500.

После заполнения полей нажмите кнопку «Добавить». Приложение предварительно проверит введённые данные. Если обнаружены ошибки, соответствующие поля будут отмечены значками с пояснениями.

При успешном создании сервер сохранит мероприятие, после чего приложение обновит таблицу и выведет сообщение об успешном добавлении.

Если в указанной аудитории на выбранную дату уже существует мероприятие, сервер отклонит создание записи.

5. Поиск мероприятий

Для поиска введите название мероприятия или аудиторию в поле поиска и нажмите кнопку «Найти».

Поиск выполняется по уже загруженным данным без отправки отдельного запроса на сервер. Результаты отображаются в таблице, а строка состояния показывает количество найденных мероприятий.

Для отображения полного списка загруженных мероприятий нажмите кнопку «Сбросить».

6. Отмена загрузки

Если загрузка выполняется слишком долго, нажмите кнопку «Отмена». Приложение отправит запрос на отмену текущей операции и восстановит доступность элементов управления.

После отмены загрузки операцию можно выполнить повторно, нажав кнопку «Загрузить».

7. Обработка ошибок

При работе с приложением могут возникать следующие ошибки:

Сообщение Причина Что делать
Название должно содержать от 5 до 150 символов. Название пустое или не соответствует допустимой длине. Введите название длиной от 5 до 150 символов.
Укажите аудиторию. Поле аудитории не заполнено. Укажите название аудитории.
Сервер обнаружил ошибки в заполнении данных. Исправьте поля, отмеченные значками. Сервер обнаружил ошибки проверки введённых данных. Исправьте поля, отмеченные значками ошибок.
Аудитория занята. В этой аудитории на выбранную дату уже существует мероприятие. Выберите другую дату или аудиторию.
Нет связи с сервером. Проверьте, запущен ли сервис. Сервер EventsApi недоступен. Проверьте запуск сервера и повторите операцию.
Сервер не ответил за отведённое время. Истекло время ожидания ответа при загрузке мероприятий. Проверьте доступность сервера и повторите операцию.
Превышено время ожидания ответа сервера. Истекло время ожидания ответа при создании мероприятия. Повторите операцию позднее.
Не удалось загрузить мероприятия. Произошла непредвиденная ошибка при загрузке данных. Повторите операцию. Если ошибка сохраняется, проверьте работу сервера.

Ошибки заполнения отображаются с помощью значков рядом с соответствующими полями. При возникновении проблем с подключением или ответом сервера приложение показывает отдельное информационное сообщение.

8. Вопросы и ответы

Вопрос: Почему список мероприятий не загружается?

Ответ: Проверьте, запущен ли сервер EventsApi и доступен ли он по адресу http://localhost:5289.

Вопрос: Почему не удаётся создать мероприятие?

Ответ: Проверьте заполнение обязательных полей и соответствие введённых значений установленным ограничениям.

Вопрос: Почему приложение сообщает, что аудитория занята?

Ответ: В указанной аудитории на выбранную дату уже существует мероприятие. Выберите другую дату или аудиторию.

Вопрос: Можно ли отменить загрузку списка?

Ответ: Да. Для этого необходимо нажать кнопку «Отмена» во время выполнения загрузки.

Вопрос: Как вернуться к отображению всех мероприятий?

Ответ: Нажмите кнопку «Сбросить».

Вопрос: Почему поиск не находит нужное мероприятие?

Ответ: Поиск выполняется по уже загруженным данным. Для получения актуального списка сначала нажмите «Загрузить».

Вопрос: Где посмотреть дополнительную информацию о программе?

Ответ: Откройте меню «Справка» и выберите пункт «О программе».

9. Дополнительная информация

Для получения информации о версии приложения откройте меню «Справка» и выберите пункт «О программе».

Для просмотра дополнительной документации API можно воспользоваться Swagger по адресу http://localhost:5289/swagger.
