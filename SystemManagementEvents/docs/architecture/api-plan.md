# План API: мероприятия организации

Сущность: Event (мероприятие)

| Поле            | Тип      | Кто задаёт   | Правило проверки                          |
|-----------------|----------|--------------|-------------------------------------------|
| Id              | int      | сервер       | —                                         |
| Title           | string   | пользователь | обязательно, 5–150 символов               |
| Date            | DateTime | пользователь | обязательно                               |
| Room            | string   | пользователь | обязательно                               |
| MaxParticipants | int      | пользователь | от 1 до 500                               |
| Status          | string   | сервер       | при создании — «Черновик»                 |
| CreatedAt       | DateTime | сервер       | текущее время                             |

| Метод  | Адрес              | Действие              | Коды ответа     |
|--------|--------------------|-----------------------|-----------------|
| GET    | /api/events        | Список мероприятий    | 200             |
| GET    | /api/events/{id}   | Одно мероприятие      | 200, 404        |
| POST   | /api/events        | Создать мероприятие   | 201, 400, 409   |
| DELETE | /api/events/{id}   | Удалить мероприятие   | 204, 404        |

Бизнес-правило: нельзя создать два мероприятия в одной аудитории в один день → 409 Conflict.
